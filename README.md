## ✨ Design & Engineering Highlights

- **📈 SVG Scroll-Driven Path Animation:** Implements custom SVG path tracing that visually maps user credit growth milestones as the viewport scrolls.
- **💳 Multi-Layer Parallax Card Display:** Physics-inspired multi-plane parallax depth for credit card assets responding to user scroll position.
- **🌊 Ultra-Smooth Inertial Scrolling:** Integrated Lenis smooth scroll engine for frictionless 60 FPS page dynamics and viewport velocity.
- **💬 Interactive Testimonials Carousel:** Spring-animated client results carousel featuring star ratings, timeline milestones, and dynamic slide transitions.
- **🌗 Dual Theme Engine:** Smooth theme switching between clean Light and dark financial UI themes.
- **🧭 Intelligent Floating Navigation:** Smart header that appears dynamically on deep scroll with active section detection and persistent floating CTA.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+ or 20+
- npm or pnpm

```bash
# 1. Clone the repository
git clone https://github.com/Akshayjg2204/credit_repair.git
cd credit_repair

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Building for Production
```bash
npm run build
```
